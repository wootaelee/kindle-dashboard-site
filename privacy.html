Privacy policy

Kindle dashboard · last updated November 22, 2026

Kindle dashboard is a personal project used by a single household. It is not a public service and does not have other users.

What it accesses

With the owner's permission, it reads their own Google Nest thermostat through Google's Smart Device Management API: the device name, indoor temperature, humidity, thermostat mode, set temperature, and whether it is heating, cooling or online. Access is read-only; it never changes any settings.

How the data is used

The readings are drawn onto an image shown on the household's own e-reader. They are held only in memory on the owner's home computer for a few minutes and are not stored long-term.

Sharing

The data is not sold, shared, or sent to anyone. It never leaves the owner's home network except for the requests to Google that fetch it.

Revoking access

Access can be removed at any time from Google Nest partner connections or Google account permissions.
